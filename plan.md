## Initial Thoughts

All four tasks are pretty identical in project design. The key difference is in file source for RAG (sort of) and prompt engineering.

The first thing that I think is important is to consider what LLM I want to use. Naturally, later in the project I will want a larger, powerful inference model, but in the meantime it would make sense to find a small, open source model I can run locally with a simple prompt. 

[This page for small LLMs](https://mljourney.com/top-10-smallest-llm-to-run-locally/) suggests that [Tiny Llama 1.1B](https://huggingface.co/TinyLlama/TinyLlama-1.1B-Chat-v1.0) will fit within my PC constraints. I would think it sensible to enable model switching in the final product so implementing this would be sensible for now.

### Task selection

I think I will select Option 4: Career Intelligence Assistant as this will provide me with a few avenues for different methods of discussion.

I will initially require the user to upload their CV and then paste in a JD. This is the simplest system I can create. I will then create a mock Job Board with fake job postings generated by copilot and encourage the LLM to locate appropriate jobs.
